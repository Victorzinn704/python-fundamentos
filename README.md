# Fundamentos de Python

Coleção de 41 exercícios de lógica, condicionais, repetição e programação
orientada a objetos. Os arquivos originais estão em `exercicios/`.

Requer Python 3.10+. Execute um exercício por vez:

```sh
python3 exercicios/python2.py
python3 -m compileall -q exercicios
```

Há exercícios interativos, exemplos incompletos e cálculos didáticos. Compilar
valida a sintaxe; não comprova a regra de negócio de cada exercício. Não use
estes cálculos como orientação médica ou financeira.

O sistema de login com testes e camadas está no projeto
[login-poo-python](https://github.com/Victorzinn704/login-poo-python).

Consulte [arquitetura](docs/architecture.md) e [segurança](SECURITY.md).
