# Organização

Cada arquivo em `exercicios/` é uma atividade independente. Não há banco, API
nem credenciais externas. A estrutura simples evita impor dependências e
camadas a scripts de estudo. Novos sistemas com estado e casos de uso próprios
devem ganhar módulos e testes antes de crescerem nesta coleção.

O CI compila todos os arquivos e verifica segredos. Não há alegação de TDD:
os exercícios foram escritos antes desta organização.
